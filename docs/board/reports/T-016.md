## Hasil
- **CI**: job `e2e` di `.github/workflows/ci.yml` kini menjalankan step **"Audit aksesibilitas katalog (axe)"**: setelah `playwright install chromium --with-deps` → `pnpm --filter @trailgate/web build` → `next start -p 3000` di latar belakang → loop tunggu HTTP 200 (60×1 dtk) + cek akhir → `node packages/ui/scripts/axe-katalog.mjs --base http://127.0.0.1:3000`, dengan `trap 'kill "$pid"' EXIT INT TERM` dan exit code dipertahankan (fail-closed; tanpa `|| true`).
- **Lokal**: target `make axe` (port 3100 via `AXE_PORT`/`AXE_BASE`) melakukan urutan sama; masuk `make ci`; tercatat di `make help`.
- **Makefile**: `.PHONY: web-build` diekstrak agar `tokens-budget` dan `axe` berbagi satu `next build` per `make ci`.
- **README**: subbagian "Perintah CI (Makefile)" (baris ~116-133) mendokumentasikan `make ci`/`make axe`/`make e2e`, port, fail-closed, prasyarat Chromium.

## Bukti (dijalankan nyata)
- `make axe` → **exit 0**, 59,6–99,7 dtk: `Rute katalog (14)` termasuk `/katalog/tenant-theme`; `axe-katalog: 14 halaman, 0 violations, 0 serious/critical, 0 halaman gagal`.
- Hitung independen: 14 direktori katalog berisi `page.tsx` = N=14.
- Parser YAML ketat (menolak kunci ganda) → OK, 14 job; `make -n axe` + `make -n ci` parse.
- Trap efektif: setelah run, `curl http://127.0.0.1:3100/` → connection refused (000); tak ada listener 3000/3100.
- Runner GHA: **unverified** (tidak tersedia di mesin ini) — divalidasi lewat perintah setara lokal.

## Terbuka (non-blocking, sudah dicatat di kartu)
- **P2 laten (tg-ux F-4)**: step axe memakai `:3000` lalu mematikannya; step Playwright memakai `E2E_NO_WEBSERVER=true` + target `:13000` tanpa server → akan menggagalkan job begitu spec T-101 mendarat. Diperbaiki saat itu (satu server bersama atau arahkan Playwright ke `:3000`).
- **P3 (tg-reviewer F-1)**: contoh exit code di README salah (`exit 2` untuk "direktori katalog kosong"; sebenarnya exit 3 untuk direktori hilang, exit 2 hanya untuk gate-pending).
- **P3 (tg-reviewer F-2)**: `kill "$pid"` mematikan wrapper `pnpm`, bukan process group — diuji dan **tidak** meninggalkan server berport di jalur normal; mitigasi (process group + guard `EADDRINUSE`) dicatat sebagai utang.
- **P3 (tg-reviewer F-3)**: saat server gagal siap, `/tmp/axe-web.log` tidak di-`cat` dan tidak di-upload → diagnosa di GHA perlu run ulang.
